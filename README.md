# 数据结构与算法实验

根据《数据结构与算法实验指导书》实现三次实验，使用 C11。
代码采用结构体、数组、指针和递归等课程知识，每个实验单独编译运行。

## 文件

| 实验 | 源文件 | 内容 |
| --- | --- | --- |
| 实验一 | lab1/linear_list.c | 顺序表、带头结点的单链表 |
| 实验二 | lab2/binary_tree.c | 二叉树构造、遍历、统计和释放 |
| 实验三 | lab3/prim.c | 共享充电桩线缆铺设，邻接矩阵和 Prim 算法 |

## 编译运行

在仓库根目录执行，需要 GCC。

```sh
gcc -std=c11 -Wall -Wextra lab1/linear_list.c -o /tmp/lab1
gcc -std=c11 -Wall -Wextra lab2/binary_tree.c -o /tmp/lab2
gcc -std=c11 -Wall -Wextra lab3/prim.c -o /tmp/lab3
/tmp/lab1
/tmp/lab2
/tmp/lab3
```

Windows 下也可以分别用支持 C11 的 IDE 打开源文件编译。源文件为 UTF-8，终端应使用 UTF-8 显示中文。

### 实验一

依次输入 1、2、0，演示两种存储结构的建表、查找、插入、删除和遍历。
每次演示重新建立含 10、20、…、80 的表。
在第 4 个位置插入 45，再删除第 6 个元素，结果为

```text
10 20 30 45 40 60 70 80
```

位序从 1 开始。顺序表最多存放 20 个元素。
查找分别按指导书返回位序或结点指针，修改操作返回 OK/ERROR，遍历和销毁无返回值。
LinkCreate 使用状态返回值，以便调用方判断内存分配是否成功。

这组操作中，顺序表插入移动 5 个元素，删除移动 3 个元素。
单链表插入进行 2 次链接指针赋值，删除修改 1 次前驱的 next，并释放结点。
链表仍然需要先遍历定位前驱，按位序插入和删除的整体时间复杂度也是 O(n)。
顺序表适合频繁按下标访问，链表适合已经定位前驱后的插入删除。

### 实验二

输入先序扩展序列，用 # 表示空子树，可以在字符之间加空格。

```text
ABD##E##C#F##
```

对应树形

```text
    A
   / \
  B   C
 / \   \
D   E   F
```

预期输出

```text
先序遍历：A B D E C F
中序遍历：D B E A C F
后序遍历：D E B F C A
树的深度：3
结点总数：6
叶子结点数：3
度为 1 的结点数：1
```

空树输入 #，单结点树输入 A##。
构造函数使用状态返回值和根指针参数，区分空树与构造失败。
输入不完整时，交互终端需要结束输入（Linux 下 Ctrl+D），程序会报错并释放已构造的结点。

### 实验三

采用指导书正文的充电桩场景，从 0 号点位开始。
点位数为 1~8，顶点编号从 0 开始，边数不能超过 n(n-1)/2。
为保证 INF=99999 大于全部边权之和，程序将单条成本限定为 1~3000。
拒绝自环、重复边、非法编号和非正成本。

常规连通用例

```text
5 7
0 1 2
0 2 4
1 2 1
1 3 5
2 3 3
2 4 6
3 4 2
```

选边顺序为 (0,1)、(1,2)、(2,3)、(3,4)，总成本为 8 万元。
每轮完成选边并更新后，程序输出 lowcost 和 adjvex。

| 轮次 | lowcost | adjvex |
| --- | --- | --- |
| 初始 | 0 2 4 INF INF | 0 0 0 0 0 |
| 1 | 0 0 1 5 INF | 0 0 1 1 0 |
| 2 | 0 0 0 3 6 | 0 0 1 2 2 |
| 3 | 0 0 0 0 2 | 0 0 1 2 3 |
| 4 | 0 0 0 0 0 | 0 0 1 2 3 |

不连通用例

```text
4 2
0 1 3
2 3 4
```

输出“无法全部连通！”，不会输出总成本。

单点用例输入 1 0，总成本为 0。
两点用例输入 2 1，再输入 0 1 3000，总成本为 3000。
