# 实验一代码详解

对应源文件为 [linear_list.c](linear_list.c)。本实验用两种存储方式实现同一个线性表，位序统一从 1 开始。

## 一、头文件与常量

stdio.h 提供 printf、scanf，stdlib.h 提供 malloc、free。
MAXSIZE 为 20，表示顺序表数组的容量。
OK 为 1、ERROR 为 0，修改操作通过这两个状态告诉调用者是否成功。

## 二、两种结构体

SqList 中的 data 数组存储元素，length 记录实际长度。
数组下标从 0 开始，所以第 i 个元素对应 data[i-1]。
数组容量和实际长度不同，例如容量为 20 时，也可以只存 8 个元素。

LNode 表示一个链表结点，data 保存整数，next 保存下一个结点的地址。
LinkList 是 LNode 指针类型的别名。
链表带头结点，头结点的 data 不使用，其 next 指向第一个有效元素。
空链表的头结点仍然存在，只是 next 为 NULL。

## 三、顺序表各函数

### SeqInit

接收 SqList 指针，把 length 设为 0，返回 OK。
传入 &L 后，函数中的 L->length 修改的是调用方的表。
初始化无需清空数组，因为 length 为 0 时，数组里的旧值不属于有效元素。

### SeqCreate

先检查 n 是否在 0~20 内。非法长度直接返回 ERROR。
循环将 data[i] 设为 (i+1)*10，因此生成 10、20、…。
填充完成后把 length 设为 n，返回 OK。

### SeqLocate

从下标 0 开始逐个比较，找到后返回 i+1，即元素位序。
循环结束还没找到就返回 0。
遇到重复值时返回第一个匹配元素的位序。
本函数传入 SqList 的副本，只读取数据。

### SeqInsert

接收表指针、插入位序 i 和元素 e。
先检查表是否已满，以及 i 是否在 1~length+1 内。
从原表最后一个元素开始，将元素逐个向后移动一格。

```c
for (j = L->length - 1; j >= i - 1; j--)
    L->data[j + 1] = L->data[j];
```

从后往前移动可以保留尚未移动的数据。
移动完成后，把 e 写入 data[i-1]，长度加 1。
尾部插入时循环不执行，直接写入新的末尾位置。

### SeqDelete

先检查 i 是否在 1~length 内，空表自然无法通过检查。
用 *e 保存即将删除的值，让调用方能取得结果。
从下标 i 开始向前移动，将被删除位置覆盖，最后长度减 1。
调用时传入 &e，所以函数对 *e 的赋值会改变调用方变量 e。

### SeqPrint

只遍历下标 0~length-1，输出有效元素和表长。
已经删除但仍留在数组末尾的旧数据不会被输出。

## 四、单链表各函数

### LinkCreate

参数 L 是头指针的地址，函数需要通过 *L 设置调用方的头指针。
先申请头结点，把 next 初始化为 NULL。
tail 始终指向当前尾结点，每次创建新结点后，先连接再更新 tail。
使用尾指针使建表只需一次遍历，时间复杂度为 O(n)。

每次 malloc 后都判断是否为 NULL。
如果中途申请失败，调用 LinkDestroy 释放已经建立的部分，再返回 ERROR。
当前演示先令头指针为 NULL，再调用建表函数。需要重建已有链表时，应先销毁旧表。

### LinkLocate

从 L->next 开始查找，跳过头结点。
循环同时判断 p 非空以及当前数据是否匹配。
找到返回结点地址，未找到返回 NULL。
调用者必须先判断指针非空，再访问 p->data。

### LinkInsert

p 从头结点出发，走到第 i-1 个结点，即插入位置的前驱。
i 小于 1 或前驱不存在时返回 ERROR。
申请新结点 s 并保存 e，再依次执行

```c
s->next = p->next;
p->next = s;
```

第一句保存原来的后继，第二句让前驱连接新结点。
如果顺序颠倒，就会丢失原来后继的地址。
在空链表的第 1 个位置插入时，p 正好是头结点，处理方式相同。

### LinkDelete

同样先找到前驱 p。
p 不存在或 p->next 为空，都表示没有可删除的目标结点。
q 保存目标地址，*e 保存目标数据，然后让 p 跳过 q，最后 free(q)。
释放以后，不能继续读取 q->data 或 q->next。

### LinkPrint 与 LinkDestroy

LinkPrint 用临时指针 p 遍历，不移动原来的头指针，并同步统计有效结点数。
LinkDestroy 接收头指针的地址，每次先保存当前结点、推进头指针，再释放旧结点。
它会连头结点一起释放，结束后调用方的头指针为 NULL。

## 五、演示函数与主函数

SeqDemo、LinkDemo 都按建表、查找、插入、删除、遍历的顺序展示。
查找 50 可以成功，查找 55 返回未找到。
插入操作在第 4 个位置放入 45，删除操作删除新表的第 6 个元素 50。
两种结构最后都得到 10、20、30、45、40、60、70、80。

main 开头显示学号、姓名和实验名。
将两个“待填写”替换成自己的信息即可。
for (;;) 表示持续显示菜单，输入 1 或 2 调用演示，输入 0 或读取失败结束。
每次选择都会重新建表，因此上一次演示的修改不会带到下一次演示。

## 六、复杂度与核对方法

| 操作 | 顺序表 | 单链表 |
| --- | --- | --- |
| 建表 | O(n) | O(n) |
| 按值查找 | O(n) | O(n) |
| 按位序插入、删除 | O(n) | O(n)，包含定位前驱 |
| 遍历 | O(n) | O(n) |

已定位前驱后，链表插入删除只修改固定数量的链接指针，耗时 O(1)。
示例中顺序表插入移动 5 个元素，删除移动 3 个元素。
链表插入进行两次链接指针赋值，删除进行一次前驱链接修改，并释放目标结点。

编译后依次输入 1、2、0，检查两次删除值都为 50。
空表删除、非法位序、满表插入等检查可通过仓库根目录的 tests/check.py 运行。
