# 实验三代码详解

对应源文件为 [prim.c](prim.c)。
采用指导书正文的“宿舍区共享充电桩线缆铺设”场景，求连通所有点位的最低施工成本。

## 一、把实际问题表示为图

每个充电桩点位是顶点，可铺设线缆的关系是边，施工成本是边权。
线缆能够双向连接，所以使用无向带权图。
最小生成树连接全部 n 个顶点，包含 n-1 条边，总权值尽可能小。
如果原图不连通，就不存在覆盖全部点位的生成树。

## 二、常量与邻接矩阵

MAXV 为 8，限制顶点最多 8 个，编号从 0 开始。
cost[u][v] 保存 u、v 之间直接铺设线缆的成本。
对角线为 0，不存在直接连接时保存 INF=99999。
n 和 cost 是全局变量，供初始化、输入、打印和 Prim 函数共同访问。

MAXCOST 为 3000，确保最多 28 条边的成本之和不超过 84000，小于 INF。
这使 INF 能明确表示不可直接连接，同时避免本实验规模下的成本累加溢出。

## 三、InitGraph 初始化

两层循环遍历 n×n 个位置。
i==j 时设为 0，否则设为 INF。
这一步必须在确定 n 后、读入各条边之前执行。

## 四、ReadGraph 读取与校验

先读入 n、m，scanf 返回 2 才说明两个整数均读取成功。
检查顶点数在 1~8 内，边数在 0~n(n-1)/2 内。
无向简单图中，每两个不同顶点最多有一条边，所以采用这个边数上限。

随后逐条读入 u、v、w，检查编号范围、自环和成本范围。
cost[u][v] 已经不是 INF，表示该边已经输入过，程序拒绝重复边。
无向图需要同时设置 cost[u][v] 和 cost[v][u]。

全部读取成功返回 1，任何输入错误返回 0，由主函数输出错误并结束。
输入失败时不继续计算，避免把未完整读取的图当成最终数据。

## 五、PrintMatrix 与 PrintState

PrintMatrix 按行输出邻接矩阵，宽度设为 6，便于对齐。
遇到 INF 输出文字 INF，其余位置输出整数。

PrintState 输出 lowcost 和 adjvex 两个数组。
第 0 轮表示初始化状态，后面的第 i 轮表示选边并更新后的状态。
这两个数组记录 Prim 算法当前的候选连接，方便与手工推演核对。

## 六、理解两个辅助数组

lowcost[j] 表示当前生成树连接到顶点 j 的最小已知边权。
值为 0 表示 j 已经加入生成树，值为 INF 表示暂时没有直接连接到树的候选边。
adjvex[j] 保存提供这条最小候选边的树内顶点。
因此一条候选边的两个端点为 adjvex[j] 和 j。

真实成本必须大于 0，才能使用 0 作为“已入树”的标记。
已经入树的顶点，其 adjvex 值保留原记录，后续选边会跳过它。

## 七、Prim 初始化

main 调用 Prim(0)，从 0 号点位开始。
遍历所有顶点，将起点到各点的直接成本存入 lowcost，将 adjvex 设为起点。
接着把 lowcost[start] 设为 0，表示起点已经入树。
total 初始为 0，保存已经选中的边权和。

## 八、每轮选边

外层循环从 1 到 n-1，每轮增加一个顶点。
min 先设为 INF，k 先设为 -1，表示尚未找到候选点。
遍历所有顶点，跳过 lowcost 为 0 的已入树顶点，保留成本最小的候选点。

找到 k 后，选择的边为 (adjvex[k], k)，权值为 min。
输出该边，将 min 加入 total，再将 lowcost[k] 设为 0。
相同成本时，由于采用严格小于比较，会保留编号较小的候选点，生成树总成本仍然最优。

如果始终没有找到候选点，k 为 -1，说明树与剩余顶点之间没有可用的连接。
立即返回 -1，由主函数报告无法全部连通。

## 九、更新候选边

新顶点 k 加入后，可能提供更便宜的连接。
对每个尚未入树的顶点 j，比较 cost[k][j] 和原 lowcost[j]。
如果新边更便宜，就同时执行

```c
lowcost[j] = cost[k][j];
adjvex[j] = k;
```

权值和来源顶点必须同步修改，否则输出的边与成本会不对应。
更新结束后打印本轮状态。

Prim 每次选择跨越“已入树顶点集合”和“剩余顶点集合”的最小权边。
根据最小生成树的割性质，这样的选择可以扩展为一棵最小生成树。
程序始终只把新顶点接入，因此不会形成环。

## 十、示例推演

输入点位 0~4 以及指导书的 7 条边。
开始时只有 0 在树中，后续过程如下。

| 轮次 | 选中的边 | lowcost | adjvex | 累计成本 |
| --- | --- | --- | --- | --- |
| 初始 | 无 | 0 2 4 INF INF | 0 0 0 0 0 | 0 |
| 1 | (0,1)，成本 2 | 0 0 1 5 INF | 0 0 1 1 0 | 2 |
| 2 | (1,2)，成本 1 | 0 0 0 3 6 | 0 0 1 2 2 | 3 |
| 3 | (2,3)，成本 3 | 0 0 0 0 2 | 0 0 1 2 3 | 6 |
| 4 | (3,4)，成本 2 | 0 0 0 0 0 | 0 0 1 2 3 | 8 |

第 1 轮后，顶点 2 的候选成本由 4 降为 1，因为通过顶点 1 连接更便宜。
最终 4 条边连接全部 5 个点位，总成本为 8 万元。

## 十一、主函数和边界情况

main 输出学号、姓名和实验名称，两个“待填写”可替换为个人信息。
然后依次读取图、打印矩阵、运行 Prim、判断返回值。
返回值非负时输出总成本，返回 -1 时输出“无法全部连通！”。

不连通图可能在发现失败之前已经打印若干选边。
这些边属于构造过程中的部分结果，主函数不会把它们累加成有效的总成本输出。
单点图的外层循环执行 0 次，直接得到成本 0。
两点图只需选一条边，其成本就是总成本。

## 十二、复杂度与验证

邻接矩阵占 O(n²) 空间，Prim 的两个辅助数组占 O(n) 空间。
每轮扫描一次候选数组，再扫描一次新顶点的邻接关系，总时间复杂度为 O(n²)。
对最多 8 个点位的课程实验，这种实现容易理解和手工验证。

运行仓库根目录的 python3 tests/check.py，可以核对成本为 8 的常规图、
不连通图、单点图、两点图以及非法编号、重复边和非正成本等输入。
