# 实验二代码详解

对应源文件为 [binary_tree.c](binary_tree.c)。本实验的核心是递归，每次函数调用处理一棵子树。

## 一、二叉链表结构

BiTNode 有 data、lchild、rchild 三个成员，分别保存字符和左右孩子地址。
BiTree 是指向结点的指针类型。根指针为 NULL 时表示空树。
每个新结点的两个孩子先设为 NULL，保证后续失败时也能安全释放。

## 二、CreateBiTree 先序构造

参数 BiTree *T 是根指针的地址，函数用 *T 修改对应子树的根。
返回 1 表示构造成功，返回 0 表示输入不完整或内存分配失败。
因此空树也可以成功构造，成功时 *T 为 NULL。

scanf(" %c", &ch) 中，%c 前的空格用于跳过空格、换行等空白字符。
读到 # 时，这棵子树为空，直接返回成功。
读到其他字符时，申请一个结点、填写 data，然后先构造左子树，再构造右子树。

```c
CreateBiTree(&(*T)->lchild)
CreateBiTree(&(*T)->rchild)
```

取孩子指针的地址，可以让递归调用直接设置孩子指针。
两个调用用 || 连接失败判断，左边失败后会短路，不再继续构造右子树。
任何子树构造失败，DestroyTree 都会释放当前已经申请的部分，防止内存泄漏。

输入 ABD##E##C#F## 时，依次建立 A、B、D。
接下来的两个 # 表明 D 没有左右孩子，返回 B 后再建立 E。
B 的左右子树结束后返回 A，随后建立 C 和 C 的右孩子 F。

## 三、三种遍历

三个函数都先判断 T 是否为空，空树直接返回。
每个函数都会递归处理左右子树，区别在于输出根结点的时机。

| 函数 | 执行顺序 | 示例结果 |
| --- | --- | --- |
| PreOrder | 根、左、右 | A B D E C F |
| InOrder | 左、根、右 | D B E A C F |
| PostOrder | 左、右、根 | D E B F C A |

例如 InOrder(A) 会先完整输出 A 的左子树 D B E，再输出 A，最后输出右子树 C F。
每输出一个字符后加空格，方便观察各结点的先后顺序。
递归返回时会自动回到上一级调用，不需要手动保存父结点。

## 四、TreeDepth 求深度

空树返回 0。
非空树分别求出左右子树深度 left、right，取较大值再加 1。
加的 1 表示当前根结点所在的一层。
代码中的条件表达式 left > right ? left : right 用于选择较大的深度。
单结点树左右子树深度都是 0，所以深度为 1。

## 五、CountNodes 统计结点

空树返回 0。
非空树返回左子树结点数、右子树结点数与 1 的和。
其中 1 代表当前根结点，避免遗漏根。

## 六、CountLeaves 统计叶子

空树没有叶子，返回 0。
只有左右孩子同时为空，当前结点才是叶子，返回 1。
否则继续统计两个子树的叶子数并相加。
判断使用 &&，因为只缺少一个孩子的结点仍然有后继。

## 七、CountOneChild 统计度为 1 的结点

先递归取得左右子树的结果，再判断当前结点是否恰好有一个孩子。

```c
(T->lchild == NULL) != (T->rchild == NULL)
```

两个比较分别得到 0 或 1。一个孩子为空、另一个非空时，结果不同，整个表达式为 1。
两个孩子都空或都非空时，结果相同，整个表达式为 0。
示例中只有 C 恰好有一个孩子，所以结果为 1。

## 八、DestroyTree 释放内存

先判断当前根是否为空。
依次释放左子树、右子树，再 free 当前根，最后把根指针设为 NULL。
先释放孩子，才能保证访问孩子指针时根结点仍然有效。
使用指针参数也能清空调用方保存的根地址。

## 九、主函数与输入检查

main 首先声明空根指针，并输出学号、姓名和实验名称。
两个“待填写”可替换为个人信息。
接着构造树，失败时输出错误并以状态码 1 结束。
成功后使用 getchar 检查本行剩余字符，只允许空白，遇到多余字符会释放树并退出。
getchar 的结果用 int 保存，因为它还需要表示字符范围之外的 EOF。

程序随后输出三种遍历和四项统计，最后销毁树，返回 0。
构造时跳过空白，因此不能把空白字符作为结点数据，# 专门保留为空子树标记。
建议一次输入完整序列并回车。
如果序列缺少空子树标记，程序会继续等待字符，结束输入后才会报告序列不完整。

## 十、运行核对与复杂度

| 输入 | 深度 | 总结点 | 叶子 | 度为 1 |
| --- | --- | --- | --- | --- |
| ABD##E##C#F## | 3 | 6 | 3 | 1 |
| # | 0 | 0 | 0 | 0 |
| A## | 1 | 1 | 1 | 0 |
| AB### | 2 | 2 | 1 | 1 |

设结点数为 n、高度为 h。
构造、每一种遍历、每一种统计和释放都会访问每个结点，时间复杂度为 O(n)。
单个递归过程需要 O(h) 调用栈空间，树本身占 O(n) 空间。
这些递归函数适合课程中的小规模输入，极深的单链状树会受系统调用栈大小限制。
